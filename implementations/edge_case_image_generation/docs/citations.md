# Citations (edge-case image generation)

Short bibliography for notebook footnotes. Prefer primary papers; workshop
claims should point here rather than inventing authority.

## Editing / conditioning

1. **Rombach et al., 2022.** *High-Resolution Image Synthesis with Latent Diffusion Models* (LDM / Stable Diffusion).  
   https://arxiv.org/abs/2112.10752

2. **Zhang, Rao & Agrawala, 2023.** *Adding Conditional Control to Text-to-Image Diffusion Models* (ControlNet).  
   https://arxiv.org/abs/2302.05543

3. **Brooks, Holynski & Efros, 2023.** *InstructPix2Pix: Learning to Follow Image Editing Instructions*.  
   https://arxiv.org/abs/2211.09800

4. **Black Forest Labs.** FLUX.2 / Klein family (instruction and inpaint checkpoints used as the local L4 editor in this bootcamp).  
   Product / model cards: https://huggingface.co/black-forest-labs

5. **Qwen Team.** Qwen-Image-Edit (large instruction-class image editor; optional NB1.5 column).  
   https://huggingface.co/Qwen/Qwen-Image-Edit

## Detection / open vocabulary

6. **Cheng et al., 2024.** *YOLO-World: Real-Time Open-Vocabulary Object Detection*.  
   https://arxiv.org/abs/2401.17270

## Judging / embeddings (Notebook 1+)

7. **Zheng et al., 2023.** *Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena* (LLM-as-judge framing).  
   https://arxiv.org/abs/2306.05685

8. **Radford et al., 2021.** *Learning Transferable Visual Models From Natural Language Supervision* (CLIP).  
   https://arxiv.org/abs/2103.00020
