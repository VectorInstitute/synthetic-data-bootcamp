Privacy diagnostic · Distance to Closest Record (DCR)

For every synthetic row, DCR is its smallest mean absolute feature distance to any real row, normalized by each real column’s range. Features: revenue, asset turnover, operating margin, equity / assets, and cash / assets. Constant or entirely missing real columns are excluded. Missing matches missing at distance 0 and observed at distance 1. Identifiers and names are excluded. Plots share bins and axes.

DCR baseline protection = min(1, median synthetic DCR / median uniform-random DCR). The shared seeded baseline has the same sample count and draws observed numeric ranges without missing values. Higher means farther from the reference relative to this baseline, not necessarily better financial data or guaranteed privacy. Zero DCR means a match on the active features only. The real panel excludes each row itself (leave-one-out); it is a contextual reference, not held-out validation. Overfitting protection is unavailable: no independent held-out real set was used.
