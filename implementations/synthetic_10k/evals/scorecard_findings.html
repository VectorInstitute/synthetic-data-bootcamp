• Both methods state the standard facts. Of the ten questions per company, Method 1's filings state the answer for 94–100% and Method 2's for 83–100%. Real 10-Ks state 79% in a form the checker recognises; the rest are rounded or worded differently from the XBRL value.
  • Method 1 keeps its numbers exactly. When a figure is labelled as one of the ten facts ("revenues of $X", a "Total assets" row), it is correct 98.5–100% of the time, because the statements are built first and the text is checked against them.
  • Method 2 is close behind on numbers. Labelled figures are 95–97% correct. Some Item 8 tables carry "[prior year data]" placeholders, a generation defect.
  • RAG works far better on synthetic filings than on real ones. Asked through retrieval (BM25, top 10) and an LLM, the synthetic sets answer 67–93% of the questions correctly, against 37% on real filings. When retrieval finds the passage the answer is almost always right, so this score measures how findable the facts are: synthetic filings state each headline fact in a short, clearly labelled passage, while real ones bury it in long multi-year, multi-segment tables. Synthetic sets are easier than real filings, not better.
  • Realism is still the gap. Most sets write 7–56% of a real section's length. Only Method 2 on Opus matches real length (1.2–1.55×) with the closest vocabulary. No set copies real filings.
